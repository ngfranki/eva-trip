# 線上調查：喺路上嗰刻仲缺啲咩

2026-09-15 · 焦點：**旅途中使用**（唔係排行程）· app 版本 v26-1

---

## 一、一個判斷先講

查完一輪，最有用嘅結論唔係「再加功能」，而係**分清邊啲嘢唔應該由你個 app 做**。

日本行程必備嘅 app 有一批係專業工具，你個 app 唔可能贏、亦唔應該試：

| 需求 | 用邊個 | 點解唔自己做 |
|---|---|---|
| 地震／海嘯／暴雪警報 | **NERV 防災**（英文）或 **Safety Tips**（觀光廳出，專為外國旅客） | 要接氣象庁即時推送＋常駐背景。12 月北海道有實際風險，呢個一定要裝 |
| 翻譯（菜牌、講嘢） | **Google Translate**（下載離線日文包）／**VoiceTra**（NICT 出，日文語音準過 Google） | 離線模型幾百 MB |
| 離線導航地圖 | **Google Maps 自己下載範圍** | Google 唔准 cache 佢嘅地圖磚，你個 app 永遠做唔到 |
| 免稅／入境 | **Visit Japan Web** | 政府系統 |
| 交通付款 | **Suica／ICOCA**（手機 IC 卡） | 要 NFC，PWA 攞唔到 |
| 免費 Wi-Fi 自動連 | **Japan Wi-Fi Auto** | 系統層 |

**你個 app 嘅位置係：唯一知道你今日個 plan 嘅嗰個。** 所以佢應該做「**樞紐**」——喺對嘅時刻一鍵交去對嘅 app（我已經做咗北の道ナビ 吹雪／通行止め，同 Google 導航）。

## 二、A 級：零成本、直接令路上好用

### 1. `.ics` 加鬧鐘（VALARM）⭐ 回報最高

你已經可以匯出 .ics 入 iPhone 行事曆。但**冇鬧鐘**，所以只係一張表。

加 `VALARM`（標準 iCalendar，Apple 行事曆原生支援）之後，**你部 iPhone 自己會響**：
- 「30 分鐘後要出發去大涌谷」
- 「Check-in 最遲 18:00」
- 航班前 3 個鐘

**呢個係零基建拿到原生通知嘅唯一路徑。** 唔使 server、唔使推送、唔使權限。

### 2. 自動匯率（Frankfurter · 免 key · 免登記 · 冇 quota）

你而家係手入匯率。實測（2026-09-14）：

| | |
|---|---|
| 你手入 | 1 JPY = **0.0525** HKD |
| 實際 | 1 JPY = **0.05075** HKD |
| 誤差 | **3.4%** |

一個 ¥300,000 嘅行程差約 **HK$500**。Frankfurter 98 間央行、205 種貨幣、無 quota、實測連續五次全 200。
⚠️ 佢用 ECB 資料，**冇台幣（TWD）**——所以要保留手動覆寫。

### 3. 「今日一頁」

而家 63 個項目分 7 日，途中要碌。加一個「今日」視圖：只出今日，連天氣、總車程、天黑、下一站。
（「而家」卡已經答「下一站」，但答唔到「今日全日」。）

### 4. 落車後三個掂

「而家」卡加：〔到咗 ✓〕〔花咗 ¥___〕〔記一句〕。
你帶住手套、單手、車頭燈未熄——唔會為咗記一句嘢行三個入口。
（打勾、花費、日誌三樣都已經有，只係散喺三處。）

### 5. 全域搜尋

63 個項目、7 日，途中想搵「上次存嗰間拉麵」——而家唯一方法係碌完。零依賴、零成本。

### 6. 情境式一鍵交接

按項目類型出對嘅掣：
- 食嘢 → 翻譯 app（睇菜牌）
- 購物 → 免稅／Visit Japan Web
- 任何時候 → NERV 防災
- 出郊外 → 北の道ナビ（已有）

## 三、B 級：要少少工程，但值

### 7. Web Push 推送提醒

**iOS 16.4 起 PWA 真係收得到推送**（要由 Safari「加至主畫面」嗰個，唔係 Safari tab 裡面），Badging API 亦支援。
但要 VAPID key ＋ 一個排程器（Supabase 有 cron）。**第 1 項嘅 .ics 鬧鐘已經覆蓋九成需求，所以排後。**

### 8. 相片日誌

你原本要「plan **and** log」。planning 做得好，logging 仍然係純文字。你已經有 Storage、有座標、有附件上載——差嘅只係喺日誌入面擺相。

### 9. 拍單據即入帳

你已經可以擺附件。加一步：拍完單據，順手問「幾錢？」直接入花費，兩樣掛埋一齊。
（查到嘅共識：多幣種嘅重點係**保留原幣金額**，換算可以之後再算；而且要離線入得。你已經係多幣種，所以只差個快捷入口。）

## 五、一個 iOS 風險要知

> **iOS 會清走幾星期冇開過嘅 PWA 儲存。**

即係：
1. 出門前（喺 wifi）一定要重新做一次「離線準備」預載附件
2. 旅途中隔幾日開一次 app（正常用就夠）

另外確認：**iOS 唔支援 Web Share Target**——所以「由 IG／小紅書直接分享落 app」永遠做唔到，只可以貼文字（你已經有「貼文字抽地點」）。

## 七、做咗幾多（2026-09-15 更新）

你揀咗「自動匯率 → 今日一頁」，兩樣都出咗 v27-2，實機驗過：

| 項 | 狀態 | 備註 |
|---|---|---|
| 1. 自動匯率 | ✅ v27-0 | Frankfurter／ECB。12 鐘頭拉一次。你手入過嘅標「自己入」，唔會被蓋。**冇 TWD**，台幣照舊手入。實測 1 JPY = 0.05075 HKD（你原本手入 0.0525，差 3.4%） |
| 2. 今日一頁 | ✅ v27-0～27-2 | 做喺「而家」卡嘅第二個分頁。逐項有推算到達時間、營業時間衝突、附件／標註／訂單號、一粒導航掣、打勾 |
| 3. 落車後三個掂 | ❌ 未做 | |
| 4. 全域搜尋 | ❌ 未做 | |
| 5. 相片日誌 | ❌ 未做 | |
| 6. 單據變開支 | ❌ 未做 | |

順手修到嘅兩個舊 bug（都係做今日一頁嗰陣讀車程 code 撞到）：
- **行程頁車程錯位**：舊版凡有上一項就 legIdx++，連冇座標嘅「備註」「待辦」都食一格。Google 只回有座標嗰啲之間嘅 legs，所以一行備註夾喺中間，之後每段車程都錯位一格（顯示嘅係下一段嘅時間）。
- **「由 X 出發 · 1 分鐘 · 0.0 km」**：昨晚住嘅地方同今日第一項好多時就係同一間酒店（退房），出呢句係廢話。<150m 當同一個位，唔出。
